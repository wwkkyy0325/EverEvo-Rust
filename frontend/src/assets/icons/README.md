# EverEvo Icons & Assets

Single source for all graphical assets reused across the app.

## Directory structure

```
icons/
├── app/          ← application icon (.ico, .png, .svg)
├── tray/         ← system tray icons (normal, alert, busy)
├── border/       ← window border / chrome graphics
├── loader/       ← loading / progress indicators
└── README.md
```

## Usage

All assets are imported relative to this directory:

```tsx
import appIcon from '@/assets/icons/app/everevo.png';
```
